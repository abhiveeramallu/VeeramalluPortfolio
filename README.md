# Abhiram.dev — Immersive 3D Creative Portfolio

A cinematic, production-grade 3D creative portfolio website for **Veeramallu Sai Abhiram** (Computer Science Student at VIT Vellore, AI Engineer, Full-Stack Developer, and Creative Technologist).

Inspired by the visual typography and interaction design of [aayushvisuals.com](https://aayushvisuals.com/), this portfolio merges editorial art direction with real-time 3D WebGL scenes, interactive algorithmic simulations, and authentic engineering case studies.

## 🚀 Key Features

### 1. Hero Experience & 3D Interactive Terminal
- Full-screen immersive 3D canvas featuring a floating retro-futuristic terminal.
- Physical chassis with orange edge highlights, illuminated phosphor display (`> abhiram.dev`, `> AI / FULL STACK / SYSTEMS`, `> system ready_`).
- Natural floating oscillation, mouse-tracked pointer tilt, orbiting quantum rings, floating tech cubes, and atmospheric particles.
- Massive editorial typography (`ABHIRAM.`) with direct actions for Work, About, Resume, GitHub, and LinkedIn.

### 2. Selected Projects — Visual Case Studies
Large custom visual compositions with live 3D simulations and comprehensive modal deep dives:
- **01. RouteFusion**: Unified ride and parcel optimization platform featuring the Hungarian algorithm and spatial grid pruning.
  - *3D Simulation:* Miniature glowing logistics city grid with autonomous vehicles moving along optimized routes.
  - *Links:* [Live App](https://route-fusion.vercel.app/) | [GitHub](https://github.com/abhiveeramallu/RouteFusion)
- **02. ThreatLensAI**: AI-powered bot detection and threat analysis using XGBoost and behavioral biometrics.
  - *3D Simulation:* Faceted defense shield with orbiting threat nodes, radar sweeps, and telemetry rays.
  - *Links:* [GitHub](https://github.com/abhiveeramallu/ThreatlensAI)
- **03. Smart Document Intelligence**: Local-first document processing and analysis engine using Ollama local LLMs and OCR.
  - *3D Simulation:* Floating translucent document layers with a dynamic laser scanning beam and extracted token weights.
- **04. Greenhouse Micro-Climate Forecasting**: Deep learning time-series forecasting utilizing GRU and BiLSTM models.
  - *3D Simulation:* Geodesic biodome terrarium with a central pulsing thermal orb and recurrent wave nodes.

### 3. Storytelling About & Creative Skills Matrix
- Oversized typography narrative detailing graduation from VIT Vellore ('27), IBM Generative AI certification, and core philosophies.
- Interactive Skills Matrix with category filters (Languages, Frameworks, AI & ML, Databases, Tools) and real-time telemetry inspector.

### 4. Experimental Interactive Playground
Four working labs:
1. **Interactive Terminal**: Full shell emulator with commands (`help`, `about`, `projects`, `skills`, `contact`, `clear`, `matrix`, `easteregg`).
2. **AI Attention Lab**: Real-time neural token importance and intent classification simulator with attention heatmap.
3. **3D Geometry Lab**: Real-time WebGL shader customizer (switch between Torus Knot, Icosahedron, Octahedron, Dodecahedron; toggle wireframe; adjust rotation speed; customize color palettes).
4. **Hungarian Algorithm Puzzle**: A 3x3 combinatorial cost matrix mini-game where users connect drivers to orders and compute Kuhn-Munkres minimum cost.

### 5. Verified Credentials & Secure Contact Transmission
- Editorial timeline tracking education at VIT Vellore, VIT Merit Scholarship, and IBM Generative AI certification.
- Large 3D crystal core in the Contact section with direct dispatch form, 1-click clipboard copy, and verified printable resume view.

## 🛠️ Technology Stack

- **Frontend & UI:** React 18, TypeScript, Vite
- **Styling:** Tailwind CSS, PostCSS, Custom WebGL Shaders & CSS Keyframes
- **3D Graphics & Physics:** Three.js, React Three Fiber (`@react-three/fiber`), React Three Drei (`@react-three/drei`)
- **Animation & Motion:** Framer Motion, GSAP
- **Micro-Interactions & Audio:** Web Audio API sound synthesizer (hover ticks, keystrokes, success chords)
- **Icons:** Lucide React

## 💻 Getting Started Locally

```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev

# 3. Build for production
npm run build

# 4. Preview production build
npm run preview
```

Open [http://localhost:5173](http://localhost:5173) in your browser.
