# Illustration prompts

Every project already has a built-in SVG illustration. If you would rather use hand-made or generated artwork for a project, save it as `public/illustrations/<slug>.png` (or `.webp` / `.jpg`); the site picks it up at build time and shows it instead, on the home page and in the case-study header. Nothing else needs changing.

## Shared style (paste before every prompt)

> Flat editorial vector illustration, thin dark outlines, flat colour fills with minimal shading, contemporary landing-page style, single bold colour background card (blue, red, yellow, lilac or green) with a soft lighter circle behind the subject, simple props. The character is the same young South-Asian man as the reference: wavy dark hair, trimmed beard, round glasses, light-grey blazer or casual shirt, dark trousers, white sneakers. 4:3 landscape, no text, no logos.

Attach the original illustration as a character reference so the face and outfit stay consistent.
